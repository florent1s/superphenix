# Superphenix Roadmap

This document outlines the direction and priorities for the Superphenix project. It is updated by the maintainers based on community feedback and production needs.

## Current focus

- **Stabilization** — Harden core IaaS/Kubernetes integration for production use
- **Documentation** — Quickstart, architecture, and operational runbooks
- **Community** — Grow adoption and contributor base; establish regular community syncs

## Planned areas

- **GitOps & automation** — First-class Flux/Argo CD integration and day-2 automation
- **Observability** — Standardized metrics, logging, and tracing across components
- **Multi-tenancy** — Tenant isolation and RBAC patterns for MSP/CSP use cases

## How to influence the roadmap

- Open [GitHub Discussions](https://github.com/super-phenix/superphenix/discussions) for ideas and use cases
- Open [GitHub Issues](https://github.com/super-phenix/superphenix/issues) for concrete feature requests or bugs
- Contribute code or docs; maintainers prioritize community-driven work

---

*This roadmap is indicative and may change. Check the issue tracker and release notes for up-to-date plans.*
